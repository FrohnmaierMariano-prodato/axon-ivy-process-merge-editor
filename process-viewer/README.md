# Axon Ivy Process Viewer

This folder contains the React/Vite app for the Axon Ivy Process Merge Editor.

For the full feature overview (Single view, Diff view, and the **Git diff view**), see the [repository README](../README.md).

## Quick start

```bash
npm install
npm run dev      # start the dev server (typically http://localhost:5173)
npm run test     # run the unit test suite (vitest)
npm run lint     # run oxlint
npm run build    # type-check (tsc -b) and produce a production build
npm run preview  # preview the production build locally
```
